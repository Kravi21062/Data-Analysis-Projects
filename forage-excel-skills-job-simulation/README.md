# Forage Excel Skills Job Simulation

A portfolio repository documenting my completion of the **Excel Skills Job Simulation on Forage**, completed on **October 22, 2026**.

## Overview

This simulation focused on practical spreadsheet skills using account sales data. The work covered data review and organization, Excel formulas, conditional formatting, automation concepts, and dashboard-based reporting.

## Skills Practiced

- Data cleaning and organization
- Conditional formatting and data-quality review
- Excel formulas and logical functions
- Account sales analysis
- Charts and dashboard presentation
- Spreadsheet efficiency and automation concepts

## Excel Functions

Functions referenced in the simulation include:

- `SUM`
- `AVERAGE`
- `IF`
- `COUNTIF`
- `SUMIF`
- `IFERROR`

The formula practice workbook also includes examples of `MAX`, `MIN`, sales-level classification, and sales-change calculations.

## Workbook Guide

| File | Purpose |
|---|---|
| `account-sales-data-analysis.xlsx` | Account sales dataset with annual unit sales from 2016–2021 and a 5-year CAGR formula column. |
| `account-sales-data-automation-practice.xlsx` | Smaller account-sales workbook for practicing spreadsheet automation tasks. |
| `account-sales-dashboard-practice.xlsx` | Account-sales dataset, pivot-table summary, and executive sales dashboard sheets. |
| `excel-formula-practice.xlsx` | Formula practice using totals, averages, minimum/maximum values, sales levels, and sales change. |

## How to Review

1. Download a workbook from the `workbooks` folder.
2. Open it in Microsoft Excel.
3. Review the formulas and worksheets.
4. For the dashboard workbook, open the `Dashboard` sheet to view the visual summary.
5. Use the quick-reference guides in `resources` while practicing.

## Key Learning

This simulation helped me practice using Excel to organize account-sales data, calculate and summarize values, and communicate information through charts and dashboards. It also introduced the value of automating repetitive spreadsheet tasks.
